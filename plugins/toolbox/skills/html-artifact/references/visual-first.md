# 図解優先の部品と開示

この参照は図解優先モードで選んだ部品を制作するときだけ読む。共通の安全・正確さ・アクセシビリティはSKILL.mdを適用する。

## 初見で読む部分

3秒カードは「急ぐ？」「推奨は？」「止まる理由は？」など読み手の異なる問いを選ぶ。答えは「不要」「少量で試す」「材料待ち」のように短くする。判定バーは判断を一文にまとめる。安全が不明なら「未検証」を見える位置に置く。

グリッドは `repeat(3, minmax(0, 1fr))`、子要素は `min-width: 0`。狭い幅では1列にする。長いコードは `white-space: pre-wrap; overflow-wrap: anywhere`。line-clampやoverflow:hiddenで情報を隠さない。

## 関係を描く部分

### SVG流れ図

箱の幅はラベルの実際の描画幅＋左右余白、高さは行数＋上下余白で決める。矢印は箱の外を通し、線の上のラベルには背景と間隔を確保する。「旧／正」「停止／条件つきで通す」など対比を文字で示す。

viewBoxと可変幅を使い、縮小で文字が読めなくなる図は縦型へ組み替えるか図の領域だけ横スクロールにする。図全体を極小に縮めない。SVGにaccessible nameを付け、隣に関係を短く説明する。DOMの座標だけで合格とせず、文字・箱・線を実表示で確認する。

### SVGタイムライン

安全／危険の帯へ同じ意味の文字を置き、段階と期限は別の行へ配置する。日付未定は「未定」と書く。長さが期間に比例しないなら「順序のみ」と明示する。色や帯の長さで確度を誤認させない。

## 件数・選択肢を並べる部分

タイルは1件ずつ、種別・状態・関係など必要な短い属性だけ。総数と対象数を区別し、灰色の対象外にも読める文字とラベルを残す。

比較表は列に選択肢、行に同じ比較軸。推奨は見出しにも「推奨」と書く。数字の単位・母数・時点はcaptionや近くの注釈へ置き、セルの短さと判断に必要な条件が競合するときは条件を優先する。

詰まりの2列は、進められない項目と独立して進められる項目を分ける。色だけで分類せず見出しを付け、mobileでは左→右のDOM順で積む。

## 決める部分と任意の詳細

判断カードは「何を決める」「推奨」「理由」を短く示す。期限・重大な欠点・推奨が成立する条件はカードか近くの本文に残す。

詳細の開示例：

- 表層：「少量の試作を推奨。材料が未確認なら開始しない」
- details「比較の前提を見る」：試作と全量準備を比べた基準、軽微な補足。
- 必要な場合だけ詳細HTML：長い根拠・計算・コード。行き先を「計算の詳細を読む」のように示す。

summaryはkeyboardで開閉でき、focusが見えるようにする。リスクを折りたたんだ結果、推奨だけが目立つ構成にしない。詳細HTMLも同じ秘匿情報の確認対象であり、公開やアップロードは別途の権限が必要。
