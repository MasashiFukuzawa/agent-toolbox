# 情報量と図表を選ぶ判断

図表は比較・順序・量・構造を読む負担を下げる場合に使う。項目数だけで形式を決めたり、記憶容量の一般論から厳密な文字数を課したりしない。

- 主目的に効かない情報は削る。必要な補足は近くの説明・details・根拠リンクへ分ける。
- 重大リスクや推奨を変える条件は表層に残す。
- 表は同じ軸の比較、時間軸は日程、棒/区間は量と幅、レーンは担当と並行性を表す。
- 箱と矢印は実在する依存/流れに使い、単なる列挙の装飾にしない。
- 短文の方が因果や注意を明確に伝える場合は文章でよい。
- 折りたたみは読む量を選ぶ手段であって、不要な全文を保管する理由ではない。

読み手が結論とその成立条件を説明できるかで評価する。図の本数、セクション数、文字数の達成を理解の代用にしない。
