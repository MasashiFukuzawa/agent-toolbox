# ゴールのページの決まり

人が見るのは、このページ1枚である。**文字より図で語る。** 文章が多いページは読まれず、人はチャットで聞き直すことになる。書き方は `human-briefing`、見た目と図は `html-artifact`（DESIGN.md と「図で語る」）に従う。出発点は [見本](../assets/example/goal-page.html)。写して、架空の内容をすべて実際の内容に置き換える。CSSはそのまま使う。

## 置き場

- 置き場は `html-artifact` の「保存先」に従い、`<project>/YYYY-MM-DD_goal_<slug>.html` に保存する。日付は合意した日。worktreeからでも、案件の本体の名前の下に集まる。
- 案件ごとに、固定の名前の入口 `<project>/goal.html` を置く（[見本](../assets/example/goal-entry.html)）。いま進めているゴールのページへのリンクと状態だけを書く。人は、案件ごとにこの入口をブックマークする。ゴールを始めた時と終えた時に直す。
- 同じゴールは、同じファイルを直し続ける。ファイル名を変えない。
- 公開のリポジトリへ、実際のページを混ぜない。

## 構成

上から、この順に置く。1280×800の最初の画面に、タイトル・現在地・前回の確認から変わったこと・「あなたに残ること」の見出しと一覧が収まるようにする。

| 区画 | 書くこと |
|---|---|
| タイトルと更新情報 | ゴール名。更新した時刻（タイムゾーン付き）、案件名、状態、返事の宛先 |
| 現在地 | 目的を1行。受け入れの条件の進み具合の線（番号・状態の印・短い名前）と通過した数。合意・いま・期限・見込み・上限を載せた時間の帯。「やっていること」「次にやること」を1行ずつ |
| 前回の確認から変わったこと | 人が最後に返事や確認をした時からの変化を、「前 → 後」の札で3枚まで。その時刻 |
| あなたに残ること | 件数と、今日が期限の件数。2件以上なら一覧の表。1件ずつのカード。0件なら「いま、あなたに残ることはありません」 |
| 決めたこと | 任された範囲の中で決めたことのうち、利用者の見え方・制約・費用に効くもの。1件1枚の札に、番号・何を・なぜ・戻し方。根拠が数や順序なら、小さな図で示す |
| 成果と証拠 | 受け入れの条件ごとに、状態の印、確かめた結果（変更前後の対比を小さな図で）、検査した版 |
| 合意 | 何が変わるかの図（変更前後）を先頭に。目標、今日の到達点、上限、このゴールだけの許可、次の候補、合意した時と任せる範囲の版を札で。受け入れの条件の表 |
| 引き継ぎの情報 | 折りたたんで置く（人はふだん読まない）。ホストとセッション、worktree、ブランチ、最後に検査した版、PR、実行中の処理、このゴールで作ったもの（終える時に片付ける対象）、再開時に照合すること |
| 記録 | 返事をもらった質問。質問の4行は書き換えず、返事の原文・受け取った時刻・反映の結果を足す |

状態は、進行中・完了・判断待ち・作業待ち・外部待ち・中断のどれかを書く。質問を載せても、ほかに進められる作業がある間は「進行中」とし、質問の件数を添える。「判断待ち」「作業待ち」は、進められる作業が無くなって手を止めた時に書く。止まっている時は、「現在地」の「やっていること」の代わりに「再開の条件」を書く。

## 図で語る

- どの区画も、主役は図・表・札にする。文は補うだけにし、1つの区画で3行を超えたら、図に置き換えられないかを考える。
- 数は、数字を大きく見せる札か棒で示す。順序と時刻は線の上に置く。変化は「前 → 後」で並べる。選択肢は、札を横に並べて推奨を強調する。
- 状態は、色だけでなく印と文字でも示す（通過 ✓、保留 ‖ など）。
- 見本に無い種類の内容でも、同じ考えで図を選ぶ（`html-artifact` の「図で語る」の表）。飾りの図は置かない。

## あなたに残ることのカード

- 見出しの上に、番号（`Q1` から。使い回さない）・種類（判断／作業）・期限を置く。期限は日付・時刻・タイムゾーンで書き、今日なら「今日」とも書く。
- 本文は、背景・課題・目的・相談事項の4行。各行は1〜2文にし、数は札で見せる。相談事項の中に、比較が見える図を1つ置き（変更前後の図、数の棒）、選択肢は札を横に並べて、推奨と良い点・欠点を示す。折りたたまない。
- 続けて、戻せるか、決めない場合に起きること、返事のあとに起きること、返信例を、札で並べる。返信例は目立たせる。変更の大きさ・日々の使い勝手・待ち時間の根拠は、当てはまる時に足す。
- 1枚に判断は1つ。切り離せない時でも2つまで。
- 作業の依頼は、番号付きの手順と入力値、所要時間、返してほしいことを書く。秘密の値は、人の端末で入力する手順にし、ページにもチャットにも残さない。

## 更新

- 内容を変えたら、更新した時刻を直す。表示を直しただけでは変えない。
- 人が返事や確認をしたら、「前回の確認から変わったこと」を空にして、その時刻を書く。
- 数字・期日は、確かめたものだけを書く。推定は「推定」、確かめられないものは「未確認」と書く。

## 安全と表示

- script、イベント属性、外部の画像・CSS・フォントを使わない。図はinline SVGで、`role="img"` と要点を書いた `<title>` を付ける。リンクは `https:` と相対パスだけにする。
- 外から取り込んだ文字列は、`&` `<` `>` `"` をエスケープして埋め込む。
- 初めて作った時と、「あなたに残ること」が増えた時は、OSの標準の方法でページを開く。それ以外の更新では開かない。
