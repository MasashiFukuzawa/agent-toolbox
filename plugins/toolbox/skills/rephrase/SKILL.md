# Rephrase — 言い直し

直前の自分のメッセージを、内容を変えずに言い直す。`human-briefing` の4行（背景・課題・目的・相談事項。頼むことが無ければ実施事項）で、背景から順に書く。

- 平易な言葉で書く。作業中に付けた呼び名・略語・番号は、指すものを言葉で書いてから括弧に入れる。
- 読み手が知らない前提を背景に足す。新しい提案や、前のメッセージに無い結論は足さない。
- 前のメッセージに誤りを見つけたら、言い直しとは分けて、最後に1行で訂正する。

Claude Codeでは `/toolbox:rephrase`、Codexでは `$rephrase` で呼ぶ。
